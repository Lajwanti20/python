## Python Mini Projects

### 1. Shopping Billing System

A command-line billing application developed using Python that takes customer details and product prices, calculates the total bill, and applies discounts based on billing amount and membership status.

**Features:**
- Takes the customer's name as input.
- Accepts three product names and their prices.
- Stores product names and prices in lists.
- Calculates the total bill.
- Applies a 10% discount on bills of Rs. 5,000 or above.
- Applies a 5% discount on bills from Rs. 3,000 to Rs. 4,999.
- Provides an additional 2% discount when the customer has a membership and the bill exceeds Rs. 3,000.
- Displays the total bill, discount, and final payable amount.

**Python Concepts Used:**
- Variables and data types
- User input and type conversion
- Lists
- Arithmetic and comparison operators
- Logical operators
- Conditional statements (`if`, `elif`, `else`)

### 2. Student Marksheet System

A command-line student marksheet application developed using Python that calculates total marks, percentage, and grades based on marks obtained in five subjects.

**Features:**
- Takes the student's name as input.
- Accepts marks for five subjects.
- Stores marks in a list and subject names in a tuple.
- Calculates total marks out of 500.
- Calculates the student's percentage.
- Assigns a grade using `if-elif-else` conditions.
- Displays the student's name, subject marks, total marks, percentage, and grade.

**Python Concepts Used:**
- Variables and data types
- User input and type conversion
- Lists and tuples
- Arithmetic and comparison operators
- Conditional statements (`if`, `elif`, `else`)
- Basic calculations and problem-solving
